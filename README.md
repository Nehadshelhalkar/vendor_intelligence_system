Project Overview

The Vendor Intelligence System helps organizations identify and evaluate vendor risks based on supplier performance metrics. The system uses the XGBoost machine learning algorithm to classify vendors into risk categories and support procurement decision-making.

Features
Vendor Risk Prediction using XGBoost
Risk Score Generation
Interactive Risk Dashboard
Procurement Decision Support
